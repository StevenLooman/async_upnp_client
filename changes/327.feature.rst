Transport commands of ``DmrDevice`` (SetAVTransportURI, Play, Pause, Stop, Seek, Next, Previous) now wait up to 30 seconds for the response, the action response time allowed by UPnP Device Architecture 1.1 section 3.2.2, instead of the requester default (5 seconds). Some renderers answer Play only once playback has started. The timeout can be changed via ``DmrDevice.transport_action_timeout``; ``UpnpAction.async_call`` accepts a per-call ``request_timeout``.
